# Sistema de Login em Python

Projeto introdutório de um sistema de autenticação executado no terminal.

## Funcionalidades

- Solicita usuário e senha.
- Permite até três tentativas de login.
- Informa quando as credenciais estão incorretas.
- Exibe uma mensagem de sucesso após a autenticação.

## Tecnologias

- Python 3
- Entrada e saída pelo terminal
- Estruturas condicionais e repetição `while`

## Como executar

1. Instale o Python 3.
2. Abra o terminal nesta pasta.
3. Execute:

   ```bash
   python Login.py
   ```

## Observação de segurança

Este é um projeto didático. O usuário e a senha estão escritos diretamente no código, portanto o projeto não deve ser usado em produção. Antes de publicar em um repositório público, substitua essa abordagem por um mecanismo seguro de autenticação e nunca publique credenciais reais.
